# Federal Manpower Portal

A design-first Laravel 12 user interface for Federal Group of Companies.

## Included

- Premium responsive dashboard and navigation
- Recruitment, candidate, workforce, client, document, report, and settings views
- Candidate pipeline, statistics, activity chart, and responsive data table
- Branded login screen
- Alpine.js interactions via CDN
- Custom design system using `#f9e93a`, `#1c7ab4`, and `#9fcc37`

This phase intentionally contains sample data and no authentication or business logic.

## Run locally

```bash
php artisan serve
```

Open `http://127.0.0.1:8000`. The login screen is available at `/login`.
